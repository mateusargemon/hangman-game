# Hangman Game

A simple Hangman game developed in Python and played through the terminal.

## Features

- Hidden word system
- Six attempts per round
- Tracks previously guessed letters
- Final word guess
- Option to play again
- Terminal screen clearing

## Requirements

- Python 3.x

## How to Run

Clone the repository and run:

```bash
python main.py
```

## How to Play

1. Enter a word for the other player to guess.
2. Guess one letter at a time.
3. You have six attempts to guess the word.
4. After the attempts are over, you can try to guess the complete word.
5. Choose whether to play again.
